# Configuração de Wi-Fi

Como conectar seu KIT a uma rede sem fio para atualizações e download de Tools.

---

## 📶 Conectando a uma Rede

1. No Launcher, toque no ícone de configurações ⚙.
2. Selecione **Wi-Fi**.
3. O KIT fará uma varredura das redes de 2.4 GHz disponíveis.
4. Toque no nome da sua rede (SSID).
5. Digite a senha utilizando o teclado virtual na tela e clique em **Conectar**.
6. O status mudará para `Conectado` e o endereço IP será exibido.
