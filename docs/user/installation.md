# Guia de Instalação e Primeiro Uso

Parabéns pelo seu KIT! Este guia descreve o que esperar ao ligar o dispositivo pela primeira vez.

---

## 🔌 Ligando o Dispositivo

1. Conecte a bateria LiPo no conector MX1.25 ou conecte o cabo USB-C a uma fonte de energia de 5V.
2. O display AMOLED acenderá exibindo o logotipo do **KIT**.
3. O sistema carregará a tela principal do **Launcher**.

---

## 📱 Tela Inicial (Estado Sem Tools)

Se o dispositivo for novo e nenhuma Tool estiver instalada ainda, o KIT exibirá claramente:

```text
+-----------------------------+
|  KIT                   85%  |
|                             |
|                             |
|    Nenhuma Tool instalada   |
|                             |
|     [ ADICIONAR TOOL ]      |
|                             |
|                             |
|                           ⚙ |
+-----------------------------+
```

Toque no ícone de engrenagem ⚙ para abrir as **Configurações do Sistema**.
